# Atelier by Mehdi

A fashion design studio app for managing collections end-to-end.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## What's inside

- **Collections dashboard** — card grid, BARAN pre-loaded as template
- **8 stages per collection** — Mind Map, Research, Sketches, Style Cards, Patterns, CLO3D, Construction, Lookbook
- **Interactive Mind Map** — drag nodes, connect them, double-click to edit, import images
- **Style Cards** — full piece management with Shell / Lining / Insulation fabric layers
- **Image upload** — drag & drop anywhere, auto-compressed
- **Progress tracker** — auto-calculates from stage completion, or manual override
- **Export** — JSON download + browser PDF print
- **Persistent** — saves automatically to localStorage

## Build

```bash
npm run build
```
